- **Quiet Orbit** — near-black space, cobalt lines, restrained technical diagrams. Probability: 0.04.

## Committed direction: Night Signal Lab

- **Design movement:** editorial utility software with a workshop feel.
- **Core principles:** useful before persuasive, proof over hype, visible system boundaries, fast scanning.
- **Color philosophy:** graphite ink and warm paper create contrast; acid-lime marks signal action and progress; ember marks errors and attention.
- **Layout paradigm:** wide editorial canvas, asymmetric hero, dense tool index, clean stacked cards, generous negative space around forms.
- **Signature elements:** numbered tool labels, tiny status rails, grid texture, result cards with clear next steps.
- **Interaction philosophy:** every input has a visible status, every result has an obvious next action, loading states explain the work.
- **Animation:** short, purposeful transitions only; no decorative motion that competes with the tool.
- **Typography system:** bold geometric sans for display, readable sans for body, monospace for metadata and system labels.
- **Brand essence:** a small forge that turns rough inputs into useful output.
- **Brand voice:** direct, confident, specific, no hype, no emoji.
- **Wordmark/logo:** FORGE / FUNNEL, paired with an acid-lime spark cut into a dark square.
- **Signature brand color:** `#c8f169` acid signal lime.
